LIRA UNIVERSITY LIBRARY WEBSITE — COURSEWORK PROJECT

FILES
- index.html: Home page
- services.html: Library services
- staff.html: Staff profiles
- gallery.html: University gallery
- faq.html: Frequently asked questions
- css/style.css: Shared design and responsive layout
- js/script.js: Mobile menu, active navigation, FAQ accordion and footer year

HOW TO OPEN
1. Extract this folder from the ZIP file.
2. Double-click index.html.
3. Choose Microsoft Edge if Windows asks which application to use.
4. Use the navigation menu to open the other pages.

IMPORTANT OFFLINE NOTE
The HTML, CSS and JavaScript work locally. The photos, university emblem and Google Fonts are loaded from the official Lira University website / Google Fonts, so an internet connection is needed for those images and fonts to appear. The page layout and text still work without internet.

CONTENT NOTE
This is a coursework demonstration, not an official university publication. Publicly listed names and images are attributed to Lira University pages. Verify current roles, permissions, library-specific services and policies before submission.

COURSEWORK FEATURES
1. Gradients: hero, navigation and footer backgrounds.
2. Transitions: links, cards, buttons and gallery images.
3. Web fonts: DM Sans and Playfair Display.
4. Text shadows: hero and headings.
5. Animations: fade-up and floating emblem.
6. Flexbox: header, buttons and footer; CSS Grid is also used for cards and gallery.
